## Introduction

This repository contains introductory JavaScript examples and practical exercises originating from Harvard University. It covers fundamental programming concepts and demonstrates how JavaScript makes web pages interactive through DOM manipulation, event handling, and browser storage.

## Topics Covered

- JavaScript fundamentals and functions
- DOM manipulation and element selection
- Event handling and button interactions
- Changing HTML element styles dynamically
- JavaScript counters and increment operations
- JavaScript timers using `setInterval()`
- Working with forms and user input
- Creating and managing dynamic task lists
- Using `localStorage` to save browser data
- Fetching external data using the Fetch API
- Basic currency exchange-rate data retrieval

## Practical Examples

The repository includes hands-on examples such as:

- **Hello World:** Displaying messages through JavaScript functions and button clicks.
- **Color Changer:** Changing heading colors through button interactions and `data-*` attributes.
- **Counter:** Incrementing and displaying counter values.
- **Currency:** Retrieving exchange-rate data from an external API.
- **Events:** Responding to user interactions.
- **Intervals:** Automatically updating a counter every second.
- **Local Storage:** Saving and retrieving counter values in the browser.
- **Tasks:** Adding tasks dynamically through an HTML form.

## Learning Approach

The examples progress from basic JavaScript functions and DOM interactions to practical browser features such as event handling, timers, local storage, and API requests.
